# 体能测试计时系统

C# / WPF Windows 桌面程序，界面、计时逻辑、成绩存储集成在同一个应用中，可离线运行。

已适配“抽签”目录中的 Quizzer 板卡协议：自动订阅 FFE2=01，并在连接、试按准备及每组开始前向 FFE1 写入01。开始键通知后自动重新准备，掉线后可直接重连。详见《抽签按钮接入说明.md》。

赛前准备的蓝牙配置支持一个独立开始按钮和四个赛道终点按钮；开始键在现场计时页、批次已载入且四道待开始时统一发令。操作说明见《蓝牙开始按钮使用说明.md》。

顶部新增五个蓝牙连接与广播信号图标，以及“平板服务”入口。平板目前先开放1号赛道的只读联通测试页面，需电脑和平板处于互通局域网，点击启动服务后用平板浏览器打开显示的地址。服务状态与平板是否联通分别显示，详见《平板联通测试使用说明.md》。

## 直接运行

打开本目录下的 `软件\FitnessTimer.exe`。

运行环境：Windows 10 2004（19041）及以上或 Windows 11、.NET 10 Desktop Runtime。复制到其他电脑时，请复制整个“软件”目录，而不是单独复制 exe；目标电脑也需要安装 .NET 10 Desktop Runtime。

## 用 Visual Studio 打开

1. 使用 Visual Studio 2026 打开 `FitnessTimer.sln`。
2. 如提示缺少组件，在 Visual Studio Installer 中安装“.NET 桌面开发”工作负载和 .NET 10 SDK。
3. 在解决方案资源管理器中右键 **FitnessTimer**，选择“设为启动项目”。
4. 按 **F5** 调试，或 **Ctrl+F5** 直接运行。

`FitnessTimer.Checks` 是核心逻辑检查工具，不是软件界面项目。

## 操作流程

1. 在“赛前准备”配置声音及人员批次卡片，或通过 Excel 导入 `.xlsx` 名单；可在页面底部展开蓝牙绑定与检查。点击“载入此组”进入现场计时，也可在现场手动输入批次和四位选手姓名。未填写的姓名保存时采用“选手 1”等默认名称。
2. 点击“统一开始”。四条赛道采用相同的起始时间戳；可选播放系统提示音（音量、静音设置由 Windows 控制）。
3. 按各赛道的“暂停 / 继续”单独控制计时，也可统一暂停、统一继续。
4. 选手到达终点后点击该赛道“完成”。完成后计时冻结，不能继续，仍可调整罚时。
5. 两种罚时分别用加减按钮调整次数；最小为 0。总用时 = 基础用时 + 5 秒 × 次数 + 15 秒 × 次数。
6. 四条赛道全部完成后点击“保存本组成绩”。保存后锁定本组，不可重复保存或修改。
7. 在“历史成绩”查看记录、按列排序，并导出全部记录为 UTF-8 CSV，可用 Excel 打开。
8. 点击“下一组”，按卡片顺序载入下一批次的姓名并清零计时、罚时；最后一组之后提示队列结束并保留结果。没有卡片时沿用手动换组。“重置本组”只清零计时与罚时，保留当前姓名和批次。未保存时会提示确认。

## 赛前准备

页签顺序为“赛前准备”“现场计时”“历史成绩”，启动时先显示赛前准备。

- 声音：配置开始、完成、罚时、暂停、继续五类本地文件，可单独启停、试听、清除和停止试听；文件留空使用系统提示音。增加罚时播放，减少不播放；手动与蓝牙完成使用相同的完成声音。
- 人员：每批一张卡片，支持增加、删除、上下排序和指定载入；绿色边框表示当前组。
- Excel：支持标准 `.xlsx` 导入、导出和空白模板；每行一个批次，六列为顺序、批次名称、1道姓名、2道姓名、3道姓名、4道姓名。导入可追加或替换，按顺序列排列，错误文件不会部分更新名单。
- 自动换组：现场“下一组”根据卡片当前顺序载入姓名和批次；队列末尾不自动循环。重启恢复卡片与声音配置，并从首张卡片开始，可手动载入需要的组。
- 蓝牙：扫描、绑定和接收记录移入准备页底部的折叠区域，现场保留启用开关与连接状态。
- 配置自动保存到 `%LOCALAPPDATA%\FitnessTimer\preparation.json`，音频只保存路径，不复制文件。计时进行、暂停及完成未保存期间锁定声音和名单编辑。

详细说明见 `赛前准备使用说明.md`。

快捷键：**Ctrl+Enter** 统一开始 / 继续；**Ctrl+P** 暂停全部。

## 外屏投屏

点击主界面右上角的“外屏投屏”，打开独立的观众展示窗口。展示页以大字体同步显示批次、四条赛道的选手、状态、基础用时、两档罚时次数、罚时总秒数和总用时。它直接共享主界面的赛道数据，主界面暂停、完成、调整罚时、换组后自动同步，无需重新启动计时。

- 将 HDMI 显示器或投影仪连接到电脑，在 Windows 显示设置中选择“扩展这些显示器”。无线显示器也需要先由 Windows 连接。
- 检测到外屏时，展示窗口默认在首个外屏全屏打开；主界面留在操作屏。多个外屏可按 Esc 返回预览，再通过“目标屏幕”选择展示屏，点击“全屏显示”。
- 只有一块屏幕时先显示预览窗口，也可以拖到其他屏幕后按 F11 全屏。
- **F11** 或双击展示内容切换全屏，**Esc** 返回窗口模式。窗口按屏幕比例缩放展示内容。
- 更改屏幕连接后，点击“刷新屏幕”更新列表；若已断开外屏，可通过 Windows 的窗口移动功能将展示窗口移回主屏。
- 关闭展示窗口不影响主界面计时；关闭主界面时展示窗口随之关闭。重复点击“外屏投屏”会激活已有窗口。
- 此功能是本机独立展示窗口，投屏连接由 Windows 管理，不提供浏览器访问地址。

时间显示格式是 **分:秒.百分秒**，例如 `15:20.89`；超过一小时分钟数会继续增长。内部保留完整时间精度，显示时截取到百分秒。

## 蓝牙终点按钮

在“赛前准备”底部展开“蓝牙配置”，点击“扫描蓝牙”，为四条赛道选择各自的按钮并点击“连接”。默认自动识别唯一可用的通知通道，首次连接按提示识别、确认并再次试按；结果自动保存，后续通常只需连接和试按。UUID 与数据参数移入高级设置，正常使用不必填写。

支持 GATT Notify/Indicate 通知，默认整包精确匹配，可按协议设置前缀匹配。未开始、暂停中和已完成时忽略终点事件；支持防抖、过期事件过滤、断连提示、运行中停用蓝牙改用手动完成。设置窗口关闭后保留连接，程序重启后需要重新连接、试按并启用。

简化操作见 `蓝牙配置使用说明.md`，高级接入及选购条件见 `蓝牙终点按钮接入说明.md`。当前尚无按钮进行实机联调，不能保证任意蓝牙按钮兼容；普通 HID 自拍遥控器、经典蓝牙 SPP 串口按钮和仅发广播的设备需要另行适配。无线延迟需实测，不承诺专业电子计时精度。

## 数据与限制

- 历史成绩保存在当前 Windows 账户的 `%LOCALAPPDATA%\FitnessTimer\results.json`，退出后仍保留，可复制该文件备份。
- 当前进行中的计时不会自动恢复，退出前请先完成并保存；断电或强制关闭会丢失未保存的本组。
- 保存采用临时文件替换，读取损坏文件失败时禁止继续写入，避免覆盖原始历史数据。
- 此版本按四条赛道均参加设计，全部完成才能保存。
- 提示音调用发生在起始时间戳之后，声音播放存在系统延迟；本版本是人工操作计时工具，不承诺专业发令 / 光电测量精度。
- 已加入可配置的 BLE GATT 终点按钮接入，尚未实机联调；暂不包含红外门、串口设备和联网多人操作。正式测试时请避免电脑睡眠，并先进行现场试运行。
- 软件限制为当前 Windows 会话中只运行一个实例，避免重复打开后互相覆盖成绩。

## 项目结构

- `FitnessTimer/MainWindow.xaml`：现场计时、历史成绩界面。
- `FitnessTimer/MainWindow.xaml.cs`：界面操作、快捷键、文件对话框。
- `FitnessTimer/ProjectionWindow.xaml`：外屏实时展示界面。
- `FitnessTimer/DisplayMonitor.cs`：显示器检测与全屏窗口定位。
- `FitnessTimer/PreparationPanel.xaml`：声音配置、批次卡片、Excel 名单导入导出。
- `FitnessTimer/BluetoothButtonPanel.xaml`：准备页内的蓝牙扫描、赛道绑定与按键接收记录界面。
- `FitnessTimer/EventAudioPlayer.cs`：事件声音播放和系统声音回退。
- `FitnessTimer/Core/BatchQueue.cs`：卡片顺序与下一组选择。
- `FitnessTimer/Core/BatchExcel.cs`：原生 `.xlsx` 名单导入导出（ClosedXML）。
- `FitnessTimer/Bluetooth/`：BLE 扫描、GATT 订阅、连接和配置管理。
- `FitnessTimer/Core/FinishButtonController.cs`：终点按键状态校验、防抖和过期事件过滤。
- `FitnessTimer/Core/LaneTimer.cs`：独立赛道计时和罚时计算。
- `FitnessTimer/Core/ResultStore.cs`：JSON 成绩读写、CSV 导出。
- `FitnessTimer.Checks/Program.cs`：计时、存储、蓝牙协议解析及终点事件处理的核心检查。
