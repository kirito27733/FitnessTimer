# chouqian 固件更新与烧录

本项目已合并“抽签”文件夹的BLE心跳与开始键取消准备功能，并使用本机ESP-IDF v5.4.4完整编译成功。目标ESP32-C6，Flash按原配置2MB。原项目备份位于工作区artifacts/chouqian-before-heartbeat-*.zip。

## 更新内容

- 保留实体按钮GPIO19、板载指示灯GPIO2、继电器灯GPIO23。
- 保留原有开机自检：板载灯和继电器灯同时闪三次，每次亮300ms、灭300ms。
- FFE1写01：准备、亮抢答灯；写00：取消准备并熄灭抢答灯。
- FFE2通知01：实体按钮按下，只在准备状态产生一次。
- FFE3：保留绑定管理。
- FFE4读写：独立心跳版本02，写4字节序号，读返回02+最近4字节序号；不改变按钮/灯光状态。
- 连接断开时取消准备并熄灭抢答灯，失败连接重新广播。
- 保留原串口准备与按下通知，匹配当前计时软件的心跳与开始键灯光控制。
- 没有移植esp-light的电池采样；目前电量未知是正常情况，不能按其他硬件电路虚报百分比。

## 已编译的文件

使用本次生成的firmware-release目录，旧build目录是原先工程产物，不要混用。test.bin是应用固件，bootloader/bootloader.bin是启动程序，partition_table/partition-table.bin是分区表；flash_args包含本次生成的烧录参数。sha256.json是本次文件校验值。

尚未连接或烧录实体按钮，需烧录后验证心跳、发令、终点完成和实际灯光。

## 如何烧录

打开桌面的IDF PowerShell v5.4.4，关闭占用设备串口的程序，确认按钮确为ESP32-C6。进入：

```powershell
cd "E:\体能计时\chouqian\chouqian\firmware-release"
python -m esptool --chip esp32c6 --port COM5 -b 460800 --before default_reset --after hard_reset write_flash "@flash_args"
```

将COM5替换为设备管理器中的按钮串口。每个实体按钮分别烧录。该命令使用本次生成的参数，不执行全片擦除；芯片识别不匹配时不要强制烧录。写入包括启动程序、分区表和应用固件，原有配对/NVS可能因配置等因素需要重新连接验证，不能保证保留。

若连接一直等待，可按实际控制板操作BOOT/RESET进入下载模式。首次烧录后重启按钮，在计时软件重新扫描并连接；新增GATT特征如果被Windows缓存，必要时移除旧配对后重新连接。

验证：配置页出现独立心跳已启用；开始键连接后不常亮、现场载入可发令批次后亮、发令后灭；四道终点按钮均能完成；断线重连后再次验证。

## 以后重新编译

本机工具链在中文项目路径下配置失败，因此提供build-firmware.ps1：从本项目复制源码至英文临时路径编译，成功后将新烧录文件复制回firmware-release，既不自动烧录，也不覆盖旧build。

在PowerShell执行：

```powershell
cd "E:\体能计时\chouqian\chouqian"
.\build-firmware.ps1
```

默认激活脚本为本机EIM生成的C:\Espressif\tools\Microsoft.v5.4.4.PowerShell_profile.ps1，换电脑时可使用-ActivationScript指定对应脚本。不要直接沿用从原电脑复制来的旧build缓存。
