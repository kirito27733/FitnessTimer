⚠️ 当前环境不支持 Web Bluetooth，或不是安全上下文（secure context）。
Web Bluetooth 必须在 https:// 或 http://localhost 下运行， 不能直接双击打开 index.html 文件。
请在 web 目录下起个本地服务器再访问，例如：
python -m http.server 8000 然后浏览器打开 http://localhost:8000
